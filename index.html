Archive Backup

A privately operated backup integration using Google Drive to maintain authorized project archives. Built for controlled access and operational continuity.

About the Application

Alkashir Archive Backup is an independent utility configured by its operator to transfer selected backup files to an authorized Google Drive account using rclone and the Google Drive API.

Archive Storage

Maintains selected backup files in authorized Google Drive storage.

Controlled Access

Uses Google OAuth authorization and the drive.file permission scope.

Independent Operation

Runs separately from the live cashier application and its printing infrastructure.

This website is an information portal only. It does not process orders, connect to printers, perform backups or request Google sign-in from visitors.

Privacy Policy

Last updated: October 12, 2026

This website does not contain custom analytics, advertising trackers, account registration forms or browser-based access to Google Drive files.

The separately operated backup integration uses Google OAuth authorization to interact with Google Drive. Access is limited to the permissions granted by the Google account holder.

The integration is configured with the drive.file scope, which permits access to files created or specifically authorized for the application.

Authorized backup files are transferred between the configured system and Google Drive. This public GitHub Pages website is not a backup storage endpoint.

OAuth credentials and tokens are handled by the locally configured integration and are not intended to be published on this website.

Google and GitHub may process technical information according to their respective privacy policies. Users can revoke the application's Google account authorization through Google Account settings.

For questions concerning this integration, contact the operator using the address below.

Terms of Service

Last updated: October 12, 2026

Alkashir Archive Backup is a privately operated integration intended for authorized backup and archival workflows.

Only the Google account holder or an appropriately authorized operator should configure or use the integration. Authorization may be withdrawn through Google account controls.

The operator is responsible for selecting the files to be backed up, protecting credentials, managing storage availability and verifying the integrity and recoverability of backups.

This informational website does not provide a public backup service or guarantee uninterrupted access to third-party storage services.
