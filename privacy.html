ALKASHIR / ARCHIVE

Privacy Policy

Last updated: October 12, 2026

Alkashir Archive Backup is an independently operated backup integration designed to use Google Drive for authorized archival storage. This policy describes its intended access, use, storage, and handling of information.

1. Application Purpose

Alkashir Archive Backup is intended to help its operator maintain selected project backups using rclone and the Google Drive API.

The integration is separate from the live cashier application's ordering and printing systems. This public website is informational and does not perform backup operations.

2. Google User Data Access

The integration requests the Google Drive drive.file OAuth permission.

This permission allows the application to create and manage files it creates or that are specifically authorized for its use. It does not provide unrestricted access to all files in a Google Drive account.

3. How Information Is Used

When backup operations are enabled, the integration may transfer operator-selected backup files to the authorized Google Drive account, inspect permitted file metadata, and manage backup files as configured.

Google user data accessed by the integration is intended solely for these backup and archive operations, not for advertising or unrelated profiling.

4. Storage and Security

Selected backup files are intended to be stored in the Google Drive account authorized by the operator.

OAuth credentials and access tokens are maintained in the configured local environment and must not be published in the website or public source repositories.

The operator is responsible for protecting credentials, securing the operating system, and configuring appropriate encryption, retention, and recovery procedures.

5. Data Sharing

Alkashir Archive Backup is not designed to sell Google user data or disclose backup contents to advertising companies.

Backup information is transferred to Google Drive for the authorized storage purpose. Google handles information on its platform under its applicable terms and policies.

6. Retention and Deletion

Backup retention depends on the settings selected by the operator and the authorized Google Drive account.

The account holder may delete stored backup files and revoke the application's access through Google Account settings.

Revoking access stops future authorized API access but does not automatically remove previously uploaded backup files.

7. OAuth Authorization

Google OAuth is used to authorize access. The account holder controls the authorization and may revoke it at any time through Google's connected application settings.

8. Website Data

This informational website does not use custom advertising trackers, collect backup file contents, or provide a public account registration form.

GitHub Pages hosts this website and may process technical request information under GitHub's own privacy policy.

9. Policy Updates

This policy may be revised when the application's functionality or data-handling practices change. The last updated date will reflect future revisions.
